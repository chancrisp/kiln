Download **Kiln-VERSION-x64.msi** to install Kiln for everyone on the PC, or
**Kiln-VERSION-x64-portable.zip** to run it from a folder without installing.
SIGNED_LINE `SHA256SUMS.txt` lists every file's SHA-256.

The source of this release is `Kiln-VERSION-source.zip`, and the source of the
FFmpeg build it includes is `Kiln-VERSION-ffmpeg-source.zip`.
`Kiln-VERSION-symbols.zip` holds the programs' symbol files, for reading crash
reports.

Code signing policy: https://github.com/chancrisp/kiln/blob/main/docs/code-signing-policy.md
